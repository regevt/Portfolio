# 4.2x2.3 meter deck (balcony extension)

After moving into the my new house it was obvious that the deck will need to be replaced, the old one was completely rotten and beyond save.

The woods i chose for the project are **Azobe** for the supporting structure and **Bankirai** for the slats. I went for those woods because, according to my research, they are good for the outside and are somewhat wether resistant. with good care they can last for many years. 

Not knowing what I do, I decided to err on the side of caution and doubled all supporting beams. in retrospective, probably overkill.

Doing this project taught me so much about type of woods, constriction tools, and that I like woodworking.
